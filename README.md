# Лабораторна робота №3

## Тема

Динамічний HTML. Форми. Основи JavaScript.

## Назва проєкту

**TechStore — каталог продукції компанії**

## Мета роботи

Вивчити об’єктну модель документа, основи динамічного HTML та JavaScript.
Набути практичних умінь і навичок керування елементами вебсторінки, роботи з подіями, таймерами, формами та локальним збереженням даних.

## Опис проєкту

У межах лабораторної роботи сайт **TechStore** було доповнено інтерактивними елементами JavaScript.

Сайт містить:

* головну сторінку з динамічними елементами;
* сторінку каталогу з інтерактивними блоками;
* сторінку контактів із формою, рекламним блоком і блокнотом.

## Виконані завдання за методичкою

### Блок №1

#### Завдання №1

**Створити функцію, яка виводить текст із різним розміром шрифту. Функція має два аргументи: текстовий рядок і розмір шрифту. Використовуйте style-властивість fontSize.**

Було створено функцію, яка приймає текст і розмір шрифту.
Після натискання кнопки текст виводиться на сторінку з указаним розміром.

#### Завдання №2

**Використовуючи властивості елемента `IMG` `style.top` і `style.left`, зробити сторінку, на якій невелика картинка кожну секунду виникає в новому місці екрана. Використовуйте `setInterval`.**

На головній сторінці додано рухоме зображення.
За допомогою JavaScript елемент кожну секунду змінює координати `left` і `top`.

#### Завдання №3

**Знайти на сторінці всі `<p>` і змінити їхній розмір на `15px`. Використовувати `getElementsByTagName`, `setAttribute`.**

Було створено функцію, яка знаходить усі абзаци на сторінці через `getElementsByTagName`.
Після натискання кнопки для кожного абзацу встановлюється розмір шрифту `15px` за допомогою `setAttribute`.

#### Завдання №4

**Текстовий годинник — використовувати функції `setInterval` або `setTimeout` об’єкта `window`.**

На сторінці реалізовано текстовий годинник.
Функція отримує поточний час і оновлює його щосекунди за допомогою `setInterval`.

#### Завдання №5

**Створити ефект поступового витирання частини документа, використовуючи таймер.**

Реалізовано блок із текстом, який поступово зникає.
Для цього використано таймер і зміну прозорості елемента.

### Блок №2

#### Завдання №1

**У лівому верхньому кутку екрана — список із п’яти кольорів. У правому верхньому куті — чорний квадрат. Колір квадрата можна змінити, використовуючи список.**

На сторінці каталогу створено список із п’яти кольорів і квадрат.
Після вибору кольору зі списку квадрат змінює колір.

#### Завдання №2

**Створити сторінку, на якій у `DIV`-блок виводяться поточні координати курсора миші та код натиснутої клавіші на клавіатурі.**

Було реалізовано блок, у якому відображаються координати курсора миші.
Також після натискання клавіші на клавіатурі виводиться її код.

#### Завдання №3

**Створити сторінку, розмір тексту на якій можна змінювати за допомогою кнопок `A+` / `A-`. Вибір користувача запам’ятати в cookie.**

На сторінці додано кнопки `A+` і `A-`.
Вони збільшують або зменшують розмір тексту, а вибране значення зберігається для повторного відкриття сторінки.

#### Завдання №4

**Вивести на екран фразу, пофарбувавши її букви в заданий діапазон кольорів. Якщо букв більше, ніж кольорів, застосовувати кольори по колу.**

На сторінці реалізовано виведення фрази, у якій кожна літера має окремий колір.
Кольори застосовуються циклічно.

### Блок №3

#### Завдання №1

**Створити рекламний блок із кнопкою “прибрати”.**

На сторінці контактів додано рекламний блок.
Після натискання кнопки блок приховується.

#### Завдання №2

**Створити блокнот із записами, які зберігаються у `localStorage`.**

На сторінці контактів реалізовано блокнот для нотаток.
Введені записи зберігаються в `localStorage`, тому після оновлення сторінки вони залишаються доступними.

## Структура проєкту

```text
LR3_TechStore/
├── index.html
├── catalog.html
├── contacts.html
├── style.css
├── script.js
├── images/
└── README.md
```

## Опис файлів

* `index.html` — головна сторінка з JavaScript-завданнями першого блоку;
* `catalog.html` — сторінка каталогу та завдань другого блоку;
* `contacts.html` — сторінка контактів, форми, рекламного блоку та блокнота;
* `style.css` — файл стилів для оформлення сторінок;
* `script.js` — файл JavaScript-коду;
* `images/` — папка із зображеннями;
* `README.md` — опис проєкту.

## Як запустити проєкт

1. Завантажити або клонувати репозиторій.
2. Відкрити папку проєкту.
3. Запустити файл `index.html` у браузері.
4. Для переходу між сторінками використовувати навігаційне меню.
